# JMC Technical Test - Junior Programmer

Proyek technical test posisi Fullstack Developer menggunakan Node.js (Backend) dan Nuxt 3 / Vue.js (Frontend) dengan antarmuka Tabler CSS.

Oleh: Novita Lunar Pratiwi

## Status Pengerjaan
Mengingat keterbatasan waktu, fokus pengerjaan diarahkan pada penyiapan struktur awal proyek, koneksi database, serta halaman antarmuka login:
- Inisialisasi struktur proyek Backend dan Frontend.
- Konfigurasi dasar koneksi dan skema database.
- Perancangan halaman Login frontend menggunakan Tabler CSS (beserta validasi dasar).
- Bagian integrasi API penuh dan halaman CRUD lanjutan belum sempat diselesaikan karena keterbatasan waktu pengerjaan.

## Cara Menjalankan Proyek

### 1. Persiapan Database
- Buat database baru di MySQL/phpMyAdmin.
- Import file struktur SQL yang disertakan.
- Sesuaikan konfigurasi koneksi pada file `.env` di folder backend.

### 2. Menjalankan Backend
Buka terminal pada folder backend, lalu jalankan:
```bash
npm install
npm run dev
